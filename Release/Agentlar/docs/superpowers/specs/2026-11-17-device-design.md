# Personal device access v1.3
User requests Internet connection to their Windows PC and Samsung A30s, Android 11. Extend existing owner-only Telegram bot. Selected implementation: native Android Java app using SAF selected folder plus visible foreground service; PC loopback authenticated relay through Cloudflare temporary HTTPS tunnel. Alternatives USB fails Internet requirement; third-party remote desktop does not integrate agent file flow.
PC: local explicit folder selection; find/get/read UTF8 text; exact replacement preview then /pcapply nonce with stale-content check and backup. Phone: status, bounded folder filename search, retrieve files <=4MiB, send a new file copy to selected folder if app toggle enabled. No screen tapping, contacts, passwords, deletion, or app-private storage. Existing local build remains unchanged.
Commands only owner private chat. Phone pair random one-time code valid 5 minutes; per-session random bearer token; revoke cancels queue. Restart requires pairing again. Bounded HTTP bodies, timeouts, queue, filesystem scanning. Phone never contains Gemini/Telegram secrets. No camera/mic/location/Accessibility permissions. All network TLS via public tunnel; stop app or relay stops access. Host/phone must remain on and online; Android power policy can interrupt service. Quick tunnel temporary with no uptime SLA. No claim device tested unless actually exercised.
